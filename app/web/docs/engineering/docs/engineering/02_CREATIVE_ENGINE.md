# 02 · CREATIVE ENGINE

## Objetivo

Transformar conocimiento en decisiones creativas.

El Creative Engine nunca crea contenido.

Dirige el pensamiento creativo.

---

# Entrada

Proyecto

Intención

Identidad

Referencias

Observaciones

Patrones

Insights

ADN Sensorial

---

# Salida

Dirección Creativa

---

# Flujo

Recibir estado del proyecto
↓

Analizar claridad

↓

Detectar información insuficiente

↓

Seleccionar especialistas

↓

Asignar preguntas

↓

Recibir aportaciones

↓

Solicitar síntesis

↓

Validar resultado

↓

Emitir Dirección Creativa

---

# Responsabilidades

Interpretar

Priorizar

Decidir

Coordinar

Validar

Nunca producir contenido final.

---

# Reglas

No puede inventar información.

No puede ignorar referencias.

No puede saltar etapas.

Debe justificar todas las decisiones.

Debe mantener coherencia con la Identidad y el ADN.

---

# Estado

WAITING

No existen referencias suficientes.

ANALYZING

Se están generando observaciones.

DIRECTING

Se está definiendo la dirección creativa.

CONSULTING

Los especialistas están trabajando.

SYNTHESIZING

Se están integrando resultados.

READY

Existe suficiente claridad.
