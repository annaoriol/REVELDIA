# Objetivo

Definir el flujo oficial de RƎVELA.

Este documento es la referencia única para el comportamiento del laboratorio.

Todo desarrollo futuro deberá respetar este flujo.

---

# Principios

- El usuario nunca construye el sistema manualmente.
- RƎVELA acompaña, interpreta y propone.
- Cada etapa enriquece el proyecto.
- Ninguna etapa destruye información.
- Todo queda registrado en el Dossier.

Siempre la amplía.
